# Import et export

Modules : élèves, responsables, enseignants, classes, matières, notes, assiduité et emplois du temps. Télécharger le modèle CSV, prévisualiser, corriger le rapport ligne/colonne/valeur/problème/attendu, puis confirmer. Les doublons sont ignorés et comptés. Les exports utilisent UTF-8 avec BOM. Chaque import produit un rapport et une entrée d’audit ; sauvegarder avant un import important.
