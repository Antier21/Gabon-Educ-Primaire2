# Mode hors ligne

En l’absence de réseau, les écritures sont d’abord conservées dans les clés `gabon-educ:v9:*`, puis placées en file. Le bandeau indique l’état ; aucune attente distante infinie n’est nécessaire. Au retour du réseau, déclencher la synchronisation et résoudre les conflits sans écrasement silencieux. Une sauvegarde JSON reste recommandée avant une longue période déconnectée.
