# Profils d’établissement — v0.10.1

Gabon Educ+ distingue désormais six combinaisons :

- école primaire publique ;
- école primaire privée ;
- collège d’enseignement général public ;
- collège d’enseignement général privé ;
- lycée d’enseignement général public ;
- lycée d’enseignement général privé.

Le type sélectionné prépare automatiquement les niveaux :

- Primaire : CP1, CP2, CE1, CE2, CM1, CM2 ;
- Collège : 6e, 5e, 4e, 3e ;
- Lycée : 2nde, 1re, Terminale.
