# Tests import/export

Les tests couvrent CSV cité, modèles, champs obligatoires, note invalide, doublon, BOM et rapport. Manuellement, tester chaque module avec un fichier valide, vide, colonnes inconnues, accents, virgules citées, doublons et références manquantes. Vérifier la prévisualisation, le nombre créé/ignoré/rejeté, l’audit et la réouverture de l’export.
