# Gabon Educ+ v0.10.4 — Inscriptions et correctifs documents

## Objectif

Cette version corrige les retours de recette faits sur la v0.10.3 :

- les matières du primaire n'étaient pas adaptées ;
- les classes n'apparaissaient pas toujours dans les listes déroulantes du dossier élève et des documents ;
- la génération des documents pouvait afficher une page blanche ;
- il manquait une vraie page dédiée aux inscriptions dans l'onglet Scolarité.

## Nouveautés

### Page Inscriptions scolaires

Nouvelle route :

`/gabon-educ/inscriptions`

Elle est accessible depuis la navigation de l'administration, dans l'onglet **Scolarité**.

Le formulaire suit le modèle de la fiche d'identification fournie : identité de l'élève, situation scolaire, situation sociale, parents/tuteur, établissement, classe demandée et validation du dossier élève.

### Matières adaptées au profil de l'établissement

Gabon Educ+ propose maintenant des matières différentes selon le profil : primaire, collège général, lycée général ou complexe scolaire.

### Listes de classes synchronisées dans les modules

Les listes déroulantes de classes se rechargent depuis le stockage local partagé et réagissent aux changements de classes.

### Documents scolaires

Correction du composant de prévisualisation des documents afin d'éviter la page blanche provoquée par une erreur dans le modèle du bulletin primaire.

## Supabase

Aucune migration Supabase n'est nécessaire pour cette version.
