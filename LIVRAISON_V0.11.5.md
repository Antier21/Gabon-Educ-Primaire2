# Gabon Éduc+ v0.11.5

## Correctifs
- Restauration complète de la mise en page du module « Créer un enseignant » avec une grille responsive dédiée.
- Le formulaire d’activation pédagogique est séparé visuellement du bloc Matières et affectations.
- Le compteur « Classes actives » du pilotage utilise désormais les classes réellement créées dans le class-store, et non le nombre de classes contenant déjà des élèves.
- Le contrôle « classes sans titulaire/professeur principal » se base également sur les classes réellement créées.
- Les tableaux de bord principal et enseignant utilisaient déjà la source officielle `listClasses`; ils restent inchangés.
- Le fonctionnement de la grille cliquable de l’emploi du temps v0.11.4 est conservé.

Aucune nouvelle migration Supabase.
